# Customer-Churn-Analysis-Retention-Strategy-Dashboard
An interactive Power BI dashboard designed to analyze customer churn behavior, identify key risk factors, and provide actionable insights to improve customer retention strategies.

This project focuses on analyzing customer churn using the Telco Customer Churn dataset. The dashboard enables users to explore churn trends, understand customer segments, and identify high-risk groups to support data-driven retention strategies.

**The dashboard was built using the following tools and technologies:**
Power BI Desktop – Main data visualization and dashboard development tool
Power Query – Data cleaning and transformation
DAX (Data Analysis Expressions) – Used for KPIs, calculated measures, and business logic
Data Modeling – Created relationships and optimized data structure
File Format – .pbix for development and .png for dashboard preview

**Data Source**
Dataset: Telco Customer Churn Dataset
Contains 1000+ customer records with attributes like:
Demographics
Contract type
Monthly charges
Tenure
Payment methods
Churn status
This dataset is widely used for analyzing customer retention and churn prediction scenarios.

**Business Problem**
Customer churn significantly impacts revenue and growth. Businesses struggle to identify why customers leave and which segments are at higher risk.

**Goal of the Dashboard**
Analyze customer churn behavior
Identify high-risk customer segments
Provide insights to improve retention strategies
Enable decision-making using interactive visuals

This dashboard provides a comprehensive view of customer churn and enables businesses to take proactive retention measures by identifying high-risk customers and key churn drivers.
